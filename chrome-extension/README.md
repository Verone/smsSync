# Chrome Extension Setup

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select the `chrome-extension` folder
5. The extension icon should appear in your toolbar

## Configuration

1. Click the extension icon
2. Enter your backend WebSocket URL (e.g., `ws://your-backend-url.com` or `wss://your-backend-url.com` for secure)
3. Click "Save & Connect"
4. The status should show "Connected"

## Icons

You'll need to add icon files:
- `icons/icon16.png` (16x16 pixels)
- `icons/icon48.png` (48x48 pixels)
- `icons/icon128.png` (128x128 pixels)

You can create simple icons or use placeholder images for now.
